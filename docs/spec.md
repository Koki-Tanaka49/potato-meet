# Potato Meet 現在仕様

| 項目 | 内容 |
|---|---|
| バージョン | 0.3.5 |
| 更新日 | 2026-08-25 |
| 対象 | デスクトップ版Google Chrome 120以降 |
| 対象サイト | Google Meet |
| 配布状態 | ソース公開、Chrome Web Store未公開 |

## 1. 概要

Potato Meetは、Google Meetで表示中の相手の顔へポテトを重ねるChrome拡張機能です。顔の位置、向き、口の開閉をブラウザ内で検出し、ポテトの表示へ反映します。

ポテトは利用者本人のブラウザにだけ表示されます。相手へ送るカメラ映像や、ほかの参加者が見る画面は変更しません。匿名化や本人確認を目的とした機能ではありません。

## 2. 対応範囲

### 対応するもの

- デスクトップ版Google Chrome 120以降
- `https://meet.google.com/*` 上の会議画面
- 相手のカメラ映像
- 日本語と英語の自分・画面共有ラベル判定

### 対応しないもの

- 自分のカメラ映像への表示
- 画面共有への表示
- 相手へ送信する映像の加工
- 録画済み動画やGoogle Meet以外のサイト
- Chrome Web Storeからのインストール
- 目やまばたきの表示

## 3. 基本動作

1. Google Meetでポップアップを開きます。
2. 「ポテト表示」をONにします。
3. 表示中の相手カメラを検出します。
4. 顔を検出できた相手には、位置と動きへ追従するポテトを表示します。
5. 顔を確認できない映像にはポテトを表示しません。
6. OFFにすると、描画、顔検出、DOM監視、タイマーを停止してCanvasを削除します。

「ポテト表示」のON/OFFはタブ内だけで保持します。新しいMeetタブでは必ずOFFから始まります。

## 4. 対象となる参加者

- 画面内に表示され、映像を取得できる相手の`video`要素を対象にします。
- 幅80px未満または高さ60px未満の映像は対象外です。
- 同じ参加者タイルに複数の映像がある場合は、最も大きい映像を使用します。
- 自分と画面共有は、DOM属性、表示テキスト、映像トラック名から判定して除外します。
- 参加者の追加、削除、並び替え、タイルのサイズ変更へ追従します。

表示人数そのものに上限はありません。ただし、顔を確認して追従表示する人数は最大8人です。9人以上では、面積が大きい8人を対象とし、未確認の映像には表示しません。

## 5. 顔検出と動き

- MediaPipe Face Landmarkerをローカルの専用Workerで使用し、Meet画面の操作を止めにくくします。
- 1回の処理で1人分の顔を検出します。
- 2回連続で顔を検出した後に追従表示へ切り替えます。
- 顔を見失った場合は、人数ごとの検出周期に応じた短時間だけ最後の位置を維持します。
- 保持時間を超えて顔を見失った場合は非表示へ戻します。
- 顔の傾きは±25度、左右向きは±35度、上下向きは±25度へ制限します。
- 動きは前回値から35%ずつ近づけて滑らかにします。

### 口の開閉

| 状態 | 条件 |
|---|---|
| 閉じる → 開く | `jawOpen`が0.25以上 |
| 開く → 閉じる | `jawOpen`が0.17以下 |

開閉の値を分けることで、境界付近で表示が細かく切り替わることを防ぎます。

## 6. ポテト表示

### 種類

- じゃがいも
- さつまいも
- 紫いも

選択した種類は`chrome.storage.local`へ保存し、次に開いたMeetタブでも使用します。

### サングラス

- つるのないサングラスを別レイヤーで表示します。
- ポップアップからON/OFFを切り替えます。
- 設定は`chrome.storage.local`へ保存します。
- 顔の左右・上下の向きへ追従します。

### サイズと描画

- 顔検出範囲を横1.78倍、縦1.72倍へ拡大します。
- ポテトは参加者タイル内へ収めます。
- タイル下部は参加者名や操作表示のため、最大48pxを避けます。
- 画面全体で透過Canvasを1枚だけ使用します。
- ポテト本体、サングラス、口の順に描画します。

## 7. ポップアップ

ポップアップには次の項目を表示します。

- 選択中のポテトとサングラスのプレビュー
- ポテト表示のON/OFF
- 3種類のポテト選択
- サングラスのON/OFF
- 検出した参加者数と現在の負荷調整状態
- 映像を保存・送信しないことの案内

Google Meet以外のタブではポテト表示を操作できず、「Google Meetを開くと使えます」と表示します。ポテト種類とサングラスはMeet以外のタブでも変更・保存できます。

## 8. 負荷調整

| 表示人数 | モード | 検出画像の最大辺 | 次の検出まで | 追従人数 |
|---:|---|---:|---:|---:|
| 1〜4人 | 標準 | 256px | 45ms | 最大4人 |
| 5〜8人 | 調整 | 224px | 60ms | 最大8人 |
| 9人以上 | 軽量 | 176px | 90ms | 最大8人 |

顔検出は参加者ごとに順番に実行します。9人以上では、面積が大きい8人だけを顔確認の対象にします。同じ映像フレームの再検出を避け、映像・配置・設定が変化した場合だけCanvasを再描画します。非表示タブでは顔検出・描画・参加者の走査を停止します。対象映像が現れるまで顔検出Workerを起動しません。対象順序は参加者や配置が変わったときだけ更新し、対象が0件になった後は検出タイマーを止めます（初期化済みWorkerはON中は再利用します）。

## 9. プライバシーと権限

### Chrome権限

- `storage`: ポテト種類とサングラス設定の保存
- `scripting`: 開いているMeetタブとの接続が切れた場合に同梱Content Scriptを再起動
- ホスト権限 `https://meet.google.com/*`: 再接続先をMeetに限定

Content Scriptの実行先と同梱素材の公開先は`https://meet.google.com/*`だけです。

### 保存・送信しない情報

- 映像と顔画像
- 顔の位置、向き、口の開閉値
- 参加者名
- 会議URL
- 音声

CDN、分析ツール、遠隔ログは使用しません。顔検出用JavaScript、WASM、モデル、画像素材はビルド時に`dist`へ同梱し、実行時の外部通信を行いません。

## 10. ビルド

```bash
npm ci
npm run build
```

ビルドでは次の処理を行います。

1. 顔検出モデルがない場合はMediaPipe公式URLから取得します。
2. モデルのSHA-256が固定値と一致することを確認します。
3. TypeScriptを`dist`へまとめます。
4. Manifest、ポップアップ、画像、WASM、モデル、第三者ライセンスを`dist`へコピーします。

`dist`、`node_modules`、顔検出モデルはGitへ保存しません。

## 11. 確認

```bash
npm run check
npm run test:browser
```

自動確認の対象は次のとおりです。

- 顔位置と映像表示範囲の座標変換
- 口の開閉と顔向きの計算
- 自分と画面共有の除外
- 人数に応じた負荷調整
- Chromeへの拡張機能読み込み
- 画面共有の目印がない資料映像へポテトを表示しないこと
- ON/OFFの繰り返し
- ポテト種類とサングラスの切り替え
- 9人表示時の軽量モード
- 実行時の外部通信がないこと
- ポップアップのプレビュー

実際のGoogle Meetでは、2人以上の会議で顔向き、口の動き、タイル変更、15分以上の連続利用を手動確認します。

## 12. 主なファイル

```text
manifest.json               Chrome拡張機能の設定
src/content.ts              全体の制御
src/meet-adapter.ts         Google Meetの映像検出
src/face-tracker.ts         顔検出Workerとの通信
src/face-tracker-worker.ts  MediaPipeによる顔検出
src/renderer.ts             ポテトの描画
src/popup/                  ポップアップ
src/performance.ts          人数に応じた負荷調整
public/potato/              ポテト画像
scripts/                    モデル取得、ビルド、素材準備
tests/                      単体テストとブラウザ試験
```

## 13. 既知の制約

- Google MeetのDOM構造が変わると、参加者や自分・画面共有の判定が動かなくなる可能性があります。
- 日本語と英語以外では、自分・画面共有のテキスト判定を正式確認していません。
- 顔が小さい、暗い、横を向きすぎる、隠れている場合はポテトが表示されないことがあります。
- 初回ビルドには顔検出モデル取得のための通信が必要です。
- Chrome Web Store用の配布パッケージと審査資料は未作成です。

画像素材の情報は[assets.md](./assets.md)、第三者ソフトウェアとモデルの情報は[third-party.md](./third-party.md)を参照してください。
