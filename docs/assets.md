# 画像素材

## ポテト、口、サングラス

- 対象: `public/potato/*.png`
- 作成方法: OpenAIの画像生成機能で、このプロジェクト向けに新規作成
- 編集: 背景の透過、部位ごとの切り出し、余白調整、サイズ調整、色違いの作成
- 類似性: 既存作品や実在人物を意図していないオリジナル素材
- 元の指示文: 対話形式で複数回調整したため、完全な原文は保存していません

## ブラウザ試験用の顔画像

- 対象: `tests/fixtures/remote-face-open.png`
- 作成方法: OpenAI GPT Image 2.0で作成した合成人物
- 用途: 顔検出と口の開閉を確認する自動試験のみ
- プライバシー: 実在人物の写真ではありません

## 画面例

- 対象: `docs/images/*.png`
- 作成方法: ローカルの模擬Google Meet画面と拡張機能を使った自動試験で撮影
- 内容: 上記の合成人物と架空の参加者名だけを使用

画像の再利用条件は、このリポジトリ自体の利用条件に従います。現時点ではプロジェクトのオープンソースライセンスを設定していません。
