# Potato Meet

Google Meetで、自分と画面共有を除く相手の顔へポテトを重ねるChrome拡張機能です。映像はブラウザ内だけで処理し、保存・送信しません。目のレイヤーは使わず、本体と口、任意のサングラスで表情と向きを表します。Chrome 120以降を対象にしています。

## Chromeで確認する

1. ターミナルで `npm install` と `npm run build` を実行します。初回ビルド時だけ、MediaPipe公式配布元から顔検出モデルを取得してSHA-256を確認します。
2. Chromeで `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. このプロジェクトの `dist` フォルダを選びます。
6. Google Meetへ入り、Potato Meetのアイコンから「ポテト表示」をONにします。

新しいMeetタブでは必ずOFFから始まります。OFFにするとCanvas、顔検出、DOM監視を停止します。

## 実装内容

- 表示中の相手カメラを人数制限なしで検出
- 自分、画面共有、判定不能な映像を除外
- MediaPipe Face LandmarkerをWASM・モデルともにローカル実行
- 顔検出を専用Workerで実行し、Meet画面の操作を止めにくくする
- 同じ映像フレームの再検出、変化のないCanvas再描画、非表示タブでの顔検出を停止
- 4人までは標準動作、5〜8人は調整動作、9人以上は軽量動作へ自動切替
- 9人以上では大きい8人の顔を追従し、未確認の映像には表示しないことで負荷を抑制
- 口の開閉を2段階で表示（開く0.25、閉じる0.17）
- 顔の傾き、左右向き、上下向きを平滑化して反映
- 顔検出枠の横1.78倍・縦1.72倍で、髪や顎まではみ出しにくく調整
- じゃがいも、さつまいも、紫いもの3種類から選択
- つるのないサングラスを別レイヤーでON/OFFし、顔の向きへ追従
- ポップアップ上部で、選んだポテトとサングラスの組み合わせを即時プレビュー
- 選んだ種類とサングラス設定だけをChrome内へ保存（映像や参加者情報は保存しない）
- 顔を連続して確認できた映像だけに表示し、人数に応じた短い保持時間を超えて見失ったら非表示
- タイル追加・削除、サイズ変更、並び替えに追従
- 画面全体で透過Canvasは1枚だけ使用

## 確認コマンド

```bash
npm run check
npm run test:browser
```

ブラウザ試験は、Google Meetと同じURL上へローカルの模擬会議を表示し、拡張機能を実際に読み込んで確認します。実Meetでの人物の口・顔向きと15分連続利用は、2人以上で会議へ参加して最終確認してください。

ブラウザ試験の顔画像は、実在人物ではない生成画像です。

## プライバシー

- マイク、カメラ、録画、閲覧履歴の権限は要求しません。
- CDN、分析ツール、遠隔ログを使用しません。
- 映像、顔画像、顔特徴量、参加者名、会議URLを保存しません。
- 実行時に使うJavaScript、WASM、顔検出モデル、ポテト素材はすべて `dist` 内へ同梱されます。

## 公開とライセンス

このリポジトリ自体には、現時点でオープンソースライセンスを設定していません。公開状態でも、第三者に再利用・再配布の許可を与えるものではありません。

使用している第三者ソフトウェアと顔検出モデルの出典は `THIRD_PARTY_NOTICES.md`、画像素材の作成履歴は `assets/ATTRIBUTION.md` を参照してください。`dist` と顔検出モデルはGitに含めません。顔検出モデル単体の再配布条件が明示されていないため、公開配布用の拡張機能パッケージを作る場合は条件を改めて確認してください。
